# **App Name**: Surat Digital

## Core Features:

- Letter Archival & Input: Users can upload digital letter files (e.g., PDF) and input essential metadata such as sender, recipient, date, subject, and reference number for comprehensive record-keeping.
- Letter Management Dashboard: A comprehensive dashboard providing a searchable and sortable list of all archived letters, allowing users to quickly find specific documents by various criteria.
- Detailed Letter Viewer: A dedicated view for each letter that displays its full metadata and provides an integrated preview of the digital document (e.g., PDF viewer).
- Letter Editing & Deletion: Functionality to update the metadata of existing archived letters and securely remove outdated or incorrect entries from the archive.
- Excel Data Export: Enable users to export a compilation of selected or all letter metadata from the archive into a standard Excel spreadsheet format, using ExcelJS for reliable data handling.

## Style Guidelines:

- The visual scheme embraces a minimalist, professional aesthetic dominated by neutral tones. Primary UI elements, text, and critical interactions will utilize a dark, almost-black cool gray (#1E2021).
- The background will be a very light, desaturated cool gray (#F7F9FA), creating a clean and spacious feel, enhancing readability in the light color scheme.
- A subtle, desaturated cyan-gray (#738A8F) will serve as an accent color, used sparingly for highlights, active states, and non-critical calls to action, maintaining the overall neutral palette while providing clear visual differentiation.
- For both headlines and body text, the 'Inter' sans-serif font is recommended for its modern, clean, and objective appearance, ensuring excellent readability and alignment with a professional document archiving application.
- Utilize a consistent set of outline icons to complement the minimalist 'outline' UI style. Icons should be clear, simple, and functional, reflecting actions and content categories within the archive system.
- A structured and organized layout will be adopted, leveraging the capabilities of Shadcn/Radix UI components. Emphasis will be placed on clean divisions, generous spacing, and the absence of shadows, focusing on outlined elements and clear typography to define hierarchy and interactivity.
- Subtle and purposeful animations, handled by Framer Motion, will enhance user experience without being distracting. These include smooth transitions for UI element states (e.g., hover, focus), modal appearances, and view changes, ensuring a fluid and responsive interface.
